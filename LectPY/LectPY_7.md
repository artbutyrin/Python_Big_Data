## 1. Вступ: JSON та цілі лекції

**JSON** (визначення) — це текстовий формат для зберігання даних у вигляді словників (`dict`) і списків (`list`). Часто використовують для конфігів і обміну даними.

**Ви навчитеся:**

- розрізняти **скрипт** / **модуль** / **бібліотеку**;
- робити **імпорти** правильно і розуміти, що відбувається;
- ставити **3rd-party бібліотеки** через `pip` і працювати з **venv**;
- читати/писати **файли** через `with open(...)` + розуміти режими та кодування;
- працювати зі **шляхами** через `pathlib`;
- читати/писати **JSON** як практичний приклад I/O.

## 2. Скрипт — означення

**Скрипт** — файл `.py`, який **запускають напряму**.

```bash
python main.py
# python   = запускає інтерпретатор
# main.py  = файл, який виконується
```

**Ознаки скрипту:**

- має **«точку входу»** — код, який виконається при запуску;
- часто робить: **прочитати → обробити → показати/зберегти результат**.

---

## 3. Модуль — означення

**Модуль** — файл `.py`, який **імпортують в інші файли**.

**Приклад:**

```python
# utils.py (модуль)
def add(a, b):
    return a + b  # повертаємо суму
```

```python
# main.py (скрипт)
import utils
print(utils.add(2, 3))  # викликаємо функцію add з модуля utils
```

**Коротко:** модуль = «коробка з функціями/константами», яку можна підключати.

---

## 4. Імпорт: 3 базові форми

### 1) Повний імпорт модуля

```python
import math
# підключили модуль math (математика зі стандартної бібліотеки)
print(math.sqrt(9))   # викликаємо sqrt з модуля math (корінь)
print(math.pi)        # беремо константу pi з модуля math
```

### 2) Імпорт конкретного імені

```python
from math import sqrt
# взяли лише ім'я sqrt (без префікса math.)
print(sqrt(9))        # викликаємо sqrt напряму
```

### 3) Імпорт з псевдонімом

```python
import math as m
# дали модулю коротке ім'я (аліас)
print(m.sqrt(16))     # звертаємось через m
```

**Namespace (простір імен)** — «місце», де живуть назви: `math.sqrt`, `math.pi`. Різні модулі мають свої простори імен.

## 5. Де Python шукає модулі: `sys.path`

**`sys.path`** — список папок, де Python шукає імпорти.

```python
import sys
for p in sys.path:
    print(p)
# sys.path — список шляхів
# друкуємо кожен шлях
```

**Зазвичай там є:**

- папка, **звідки ви запускаєте** Python;
- **стандартні бібліотеки**;
- **`site-packages`** — де встановлені 3rd-party пакети.

## 6. Дебаг імпорту: звідки реально імпортували?

Щоб перевірити, **з якого файлу** взято модуль:

```python
import json
print(json.__file__)
# показує шлях до файлу модуля json
```

**Увага:** якщо шлях веде у **ваш проєкт** — у вас **конфлікт імен** (наприклад, створили власний `json.py`). Тоді Python підхопить ваш файл замість стандартного модуля. Такі імена краще не використовувати для своїх файлів.

## 9. Приклад модуля: `utils.py` та функція `clamp`

**Clamp** (визначення) — обмежити число в межах `[min, max]`.

**Приклад:** `clamp(10, 0, 5) → 5`, бо 10 більше 5.

**Реалізація в `utils.py`:**

```python
# utils.py
def clamp(x, lo, hi):
    """Повернути x, але так, щоб воно було між lo та hi."""
    # Спочатку min(x, hi): якщо x > hi — беремо hi, інакше x
    x_or_hi = min(x, hi)
    # Потім max(lo, ...): якщо результат < lo — беремо lo, інакше результат
    return max(lo, x_or_hi)
```

## 10. `__name__` і чому щось запускається при імпорті

У **кожному** файлі Python є змінна **`__name__`**.

| Як використовують файл | Значення `__name__` |
|------------------------|----------------------|
| Файл **запущено напряму** | `"__main__"` |
| Файл **імпортовано** | ім'я модуля (наприклад, `"utils"`) |

Це дуже важливо, щоб модулі **не робили зайвого** при імпорті (наприклад, не виводили текст у консоль і не запускали тести).

## 11. Поганий приклад: код виконується при імпорті

**utils.py (погано):**

```python
print("Я запустився!")   # цей print виконається при імпорті
def add(a, b):
    return a + b
```

**main.py:**

```python
import utils             # при імпорті виконається print у utils.py
print(utils.add(2, 3))
```

**Результат:** ви імпортували функцію, а отримали ще й «шум» у консолі. Будь-який код на верхньому рівні модуля виконується при `import`.

## 12. Правильний підхід: `if __name__ == "__main__"`

**utils.py (добре):**

```python
# utils.py (ДОБРЕ)
def add(a, b):
    return a + b

def demo():
    print("Демо: 2 + 3 =", add(2, 3))

if __name__ == "__main__":
    # ЦЕ виконається лише якщо запустити: python utils.py
    demo()
```

**main.py:**

```python
# main.py
import utils
# demo() НЕ запуститься при імпорті
print(utils.add(10, 20))   # працює спокійно
```

Код всередині `if __name__ == "__main__":` виконується **тільки** при прямому запуску файлу (`python utils.py`), а не при імпорті.

## 16. Файли: що таке «відкрити файл»

Коли ви робите `open(...)`, ви просите **ОС**:

- **знайти файл** на диску;
- **дати вам «ручку»** (доступ) до нього.

Python повертає **файловий об’єкт** — його **треба закрити** після роботи.

---

## 17. Проблема з open(): забули close()

```python
f = open("data/input.txt", "r", encoding="utf-8")   # відкрили файл
text = f.read()                                      # прочитали
# f.close()   # ЗАБУЛИ закрити
```

**Що може статися:**

- на **Windows** файл може лишитися «зайнятим» (його не вийде видалити або перезаписати);
- у довгій програмі можна **відкрити занадто багато файлів** і отримати помилку.

---

## 18. Рішення: with open(...) as f

```python
with open("data/input.txt", "r", encoding="utf-8") as f:
    text = f.read()
    # читаємо файл
# якщо тут буде помилка — файл все одно закриється автоматично
# тут файл вже точно закритий
```

**`with`** = гарантоване закриття ресурсу (файл закривається на виході з блоку, навіть при винятку).

---

## 19. Режими відкриття файлу

| Режим | Опис |
|-------|------|
| `"r"` | Читати (помилка, якщо файла нема) |
| `"w"` | Записати (**перезаписує файл повністю!**) |
| `"a"` | Дописати в кінець |
| `"x"` | Створити новий (помилка, якщо вже є) |

**Текст / бінарний:**

| Режим | Опис |
|-------|------|
| `"rt"` | (за замовчуванням) — текст |
| `"rb"` | Байти |
| `"wb"` | Запис байтів |

## 20. Читання файлу: 3 способи

**1) Весь файл в один рядок (str):**

```python
with open("data/input.txt", "r", encoding="utf-8") as f:
    all_text = f.read()
    # весь файл в один рядок (str)
```

**2) Один рядок:**

```python
with open("data/input.txt", "r", encoding="utf-8") as f:
    line = f.readline()
    # один рядок (включає \n в кінці)
    print(line.rstrip())
    # rstrip() прибирає \n та пробіли справа
```

**3) Рядок за рядком (економить пам’ять):**

```python
with open("data/input.txt", "r", encoding="utf-8") as f:
    for line in f:
        # читаємо рядок за рядком
        print(line.rstrip())
```

---

## 21. Запис у файл: write()

```python
text = "Hello\nWorld\n"
# \n = перенос рядка

with open("out.txt", "w", encoding="utf-8") as f:
    n = f.write(text)
    print("Записано символів:", n)
# write() повертає кількість записаних символів
# після with файл закритий, дані «збережені» на диску
```

**Увага:** режим `"w"` **перезаписує** файл — старий вміст зникне.

## 22. Додавання в файл: режим "a"

```python
with open("log.txt", "a", encoding="utf-8") as f:
```

## 23. try/except: безпечне читання + кольори

Комбінуємо **безпечне читання файлу** з **кольоровим виводом** (colorama):

```python
from colorama import Fore, Style

try:
    with open("data/input.txt", "r", encoding="utf-8") as f:
        text = f.read()
    print(Fore.GREEN + "ОК: файл прочитано" + Style.RESET_ALL)
except FileNotFoundError:
    print(Fore.RED + "ERROR: файл не знайдено" + Style.RESET_ALL)
```

**Тут ми:** або читаємо файл успішно, або показуємо зрозуміле повідомлення, і програма не «падає».

## 24. pathlib: сучасна робота зі шляхами

**`pathlib.Path`** робить шляхи **кросплатформними** та **читабельними**.

```python
from pathlib import Path

p = Path("data") / "input.txt"
# збираємо шлях красиво і без ручних слешів
print(p)
# data/input.txt (або data\input.txt на Windows)
```

Оператор `/` збирає шлях; на Windows автоматично використовується `\`.

## 25. JSON: що це таке (детально)

**JSON** — це **текст**, який виглядає як словники та списки.

**Приклад JSON-файлу:**

```json
{
  "name": "Hero",
  "hp": 20,
  "items": ["potion", "sword"]
}
```

**В Python це стане:**

- `dict` — для об’єкта `{ ... }`;
- `list` — для масиву `[ ... ]`.

---

## 26. Читання JSON з файлу

```python
import json
from pathlib import Path

p = Path("config.json")   # шлях до файла
with open(p, "r", encoding="utf-8") as f:
    cfg = json.load(f)
    # load = читаємо з файла → отримуємо dict/list
print(type(cfg))         # зазвичай <class 'dict'>
print(cfg["name"])       # беремо поле name зі словника
```

**Коротко:**

- **`json.load(f)`** — читає JSON **із файла**;
- **`json.loads(text)`** — читає JSON **з рядка** (string).

---

## 27. Запис JSON у файл

```python
import json
from pathlib import Path

cfg = {"name": "Hero", "hp": 20, "items": ["potion", "sword"]}
# звичайний dict/list

p = Path("config.json")
with open(p, "w", encoding="utf-8") as f:
    json.dump(cfg, f, ensure_ascii=False, indent=2)
# dump = запис у файл
# ensure_ascii=False → українські літери не перетворюються у \u0410...
# indent=2 → гарне форматування (щоб читати очима)
```

## 28. Рішення: читання–зміна–запис config.json

Повний приклад: **прочитати** конфіг, **безпечно змінити**, **записати назад**.

```python
import json
from pathlib import Path

p = Path("config.json")

# 1) читаємо
with open(p, "r", encoding="utf-8") as f:
    cfg = json.load(f)

# 2) змінюємо (обережно, щоб не зламатися, якщо ключа нема)
cfg["hp"] = int(cfg.get("hp", 0)) + 5
# get(..., 0) → якщо hp нема, беремо 0
cfg.setdefault("items", [])
# якщо items нема, створюємо порожній список
cfg["items"].append("shield")
# додаємо новий предмет

# 3) записуємо назад
with open(p, "w", encoding="utf-8") as f:
    json.dump(cfg, f, ensure_ascii=False, indent=2)
```

## Короткі висновки

- **Скрипт** — `.py`, який запускають; **модуль** — `.py`, який імпортують.
- Три форми імпорту: `import mod`, `from mod import x`, `import mod as m`.
- Модулі Python шукає в **`sys.path`**; перевірити джерело: **`модуль.__file__`**.
- Бібліотеки: **`pip list`**, **`pip show`**, **`pip show -f package`**; встановлення — **`python -m pip install ...`**; фіксація — **`pip freeze > requirements.txt`**, відновлення — **`pip install -r requirements.txt`**.
- Мінімальний проєкт: один каталог з `main.py` та модулями; **`if __name__ == "__main__":`** — щоб код не виконувався при імпорті.
- **Файли:** `open()` дає файловий об’єкт, його треба закрити; **`with open(...) as f`** — гарантоване закриття. Режими: `r`, `w`, `a`, `x`; текст/байти: `rt`, `rb`, `wb`.
- Читання: **`f.read()`**, **`f.readline()`**, **`for line in f`**. Запис: **`f.write()`** (повертає кількість символів); режим `"a"` — допис у кінець.
- **pathlib:** **`Path("data") / "input.txt"`** — кросплатформні шляхи.
- **JSON:** **`json.load(f)`** — з файла, **`json.loads(s)`** — з рядка; **`json.dump(obj, f, ensure_ascii=False, indent=2)`** — запис у файл. Безпечна зміна: **`cfg.get("key", default)`**, **`cfg.setdefault("key", [])`**.
